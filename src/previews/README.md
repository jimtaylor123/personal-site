# Local design studies

Run `npm run dev` and use the port Vite prints:

- `/preview/editorial` — warm ivory, cobalt, serif accents, wide lead project
- `/preview/studio` — charcoal, lime, oversized sans typography, studio grid
- `/preview/workshop` — purple, citrus, playful shapes and outlined panels

The top switcher links all three and the original homepage. Each uses one static portrait in About. Existing contact actions are reused. Project artwork is explicitly labelled as interface studies, not screenshots of the existing applications. Shared content lives in DesignPreview.vue; each direction's responsive styles live in preview.css. No deployment is needed.

Workshop is now also the default homepage at `/`, without the comparison bar. `/uses` and `/personal` share its visual language. The original homepage remains at `/preview/original`. Homepage copy emphasises full stack building and AI-assisted development; design and security support that focus.
